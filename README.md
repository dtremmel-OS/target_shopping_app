# Target Shopping Assistant V2.2

V2.2 adds usability, favorites, quantity controls, currency settings, budget warnings, Target buttons, and list management.

- Shopping Mode: All / Open / Done, default All
- Quantity +/- on main list and Shopping Mode
- Over-budget totals/remaining amount shown in red
- Add/edit Favorites and automatic favorite updates across lists
- Add Favorite picker from Shop tab
- Favorites show every list containing the favorite
- Improved Target buttons on main list and Shopping Mode
- Currency: USD, EUR, JPY, GBP, AUD, CAD, CHF
- AUD/CAD use $ with an AUD/CAD suffix
- Per-list menu: edit, duplicate, delete
- Shop tab: Duplicate List and Delete List
- Delete confirmation everywhere

Keep V2.2 on the V2 branch until testing is complete. Then merge into main and create v2.2.0.
