# Target Shopping List PWA — v1

A phone-first Progressive Web App for building Target shopping lists.

## Features
- Add, edit, delete and check off items
- Categories and quantities
- All/Open/Done filters
- Quick-add common items
- Target search button per item
- Local device storage
- Share list using the phone share sheet
- Offline app shell after first load
- iPhone Home Screen installation support

## Install on iPhone
1. Host these files on an HTTPS website (GitHub Pages, Cloudflare Pages, Netlify, Vercel, etc.).
2. Open the site in Safari.
3. Tap Share → Add to Home Screen.
4. Choose Add.

## Notes
The Target buttons open Target's public search URL with the item name. This version does not require Target account access and does not claim cart/order integration.
